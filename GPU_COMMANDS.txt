================================================================================
PART A: TRAINING NNU-NET SPECIALISTS (HEART, LIVER, BRAIN TUMOUR)
================================================================================

ESTIMATED TIMES (2D CONFIGURATION, 250 EPOCHS):
  1. Heart (Dataset 002):        ~1.5 to 2.0 hours
  2. Liver (Dataset 003):        ~45 minutes
  3. Brain Tumour (Dataset 001): ~2.5 to 3.5 hours
  Total for all 3:               ~5 to 6 hours

--------------------------------------------------------------------------------
OPTION 1: AUTOMATIC 1-CLICK RUNNER (RUNS ALL 3 SEQUENTIALLY)
--------------------------------------------------------------------------------
1. Pull latest scripts:
   git pull origin main

2. Double-click:
   RUN_NNUNET.bat
   (or run `.\RUN_NNUNET.bat` in PowerShell)

It will automatically:
  - Set nnUNet_raw, nnUNet_preprocessed, and nnUNet_results environment variables
  - Convert raw NIfTIs into Dataset002, Dataset003, Dataset001
  - Run plan & preprocess
  - Train 2D fold 0 for 250 epochs
  - Commit and push the summary.json results to GitHub!

--------------------------------------------------------------------------------
OPTION 2: RUN INDIVIDUAL DATASETS MANUALLY IN POWERSHELL
--------------------------------------------------------------------------------
# Step 1: Set Environment Variables (MUST RUN FIRST IN POWERSHELL):
$env:nnUNet_raw = "$PWD\data\nnunet_raw"
$env:nnUNet_preprocessed = "$PWD\data\nnunet_preprocessed"
$env:nnUNet_results = "$PWD\data\nnunet_results"

# Step 2: Convert raw datasets:
python src\nnunet_pipeline.py --dataset all

# Step 3: Run Heart (Dataset ID 2) [Fastest - ~1.5 hrs]:
nnUNetv2_plan_and_preprocess -d 2 --verify_dataset_integrity
nnUNetv2_train 2 2d 0 -tr nnUNetTrainer_250epochs

# Step 4: Run Liver (Dataset ID 3) [~45 mins]:
nnUNetv2_plan_and_preprocess -d 3 --verify_dataset_integrity
nnUNetv2_train 3 2d 0 -tr nnUNetTrainer_250epochs

# Step 5: Run Brain Tumour (Dataset ID 1) [~3 hrs]:
nnUNetv2_plan_and_preprocess -d 1 --verify_dataset_integrity
nnUNetv2_train 1 2d 0 -tr nnUNetTrainer_250epochs

--------------------------------------------------------------------------------

  data\nnunet_results\Dataset001_BrainTumour\nnUNetTrainer_250epochs__nnUNetPlans__2d\fold_0\summary.json
