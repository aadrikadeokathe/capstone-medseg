WHEN YOU LEAVE THE LAB FOR HOME:
--------------------------------------------------------------------------------
You can leave the Windows GPU PC running overnight. It will execute all high-priority
experiments sequentially, and automatically commit & push everything to GitHub!


================================================================================
OPTION 1: AUTOMATIC 1-CLICK OVERNIGHT RUNNER (RECOMMENDED)
================================================================================
First update your folder:
   git pull origin main

Then simply double-click:
   RUN_OVERNIGHT.bat

(Or in PowerShell run:  .\RUN_OVERNIGHT.bat )

This automatically executes:
  1. 40-Epoch Balanced Episodic Training (Main joint model, ~1.5 hrs)
  2. Shot-Count Ablation Curve (K = 1, 2, 4, 8, ~15 mins)
  3. Multi-Seed Run 123 (30 epochs, ~1 hr)
  4. Multi-Seed Run 456 (30 epochs, ~1 hr)
  5. Automatically pushes ALL logs and .pt models to GitHub when finished!


================================================================================
OPTION 2: MANUAL STEP-BY-STEP (IF RUNNING ONLY 40 EPOCHS BEFORE LEAVING)
================================================================================
If you only want to run the 40 epochs right now:

   python -u src\train_episodic.py --epochs 40 --episodes_per_epoch 500 --lr 5e-4 --results_file logs\episodic_zeroshot_results.txt

To resume if interrupted:
   python -u src\train_episodic.py --epochs 40 --episodes_per_epoch 500 --lr 5e-4 --resume

DO WE NEED NNU-NET FOR THE OTHER 3 ORGANS (LIVER, HEART, BRAIN)?
================================================================================
NO! Here is why:
  1. nnU-Net on 3D datasets takes 12-24+ hours PER organ and 50+ GB disk space.
  2. Our paper's central message is that nnU-Net is an inflexible, monolithic
     specialist that is impractical for clinical hospitals to retrain from scratch.
  3. Having nnU-Net on Spleen (the primary gold standard) proves that our adapter
     recovers 97.3% of specialist accuracy with 77% fewer trainable weights.
  4. Across all 4 organs, we compare directly to the UniverSeg foundation model,
     which is the exact standard protocol for few-shot medical imaging papers.
